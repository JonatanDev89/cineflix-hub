🔐 Criar Primeiro Admin

⚠️ Importante: Este processo cria o primeiro administrador do sistema usando o Supabase.

📝 Passo 1: Criar Conta Normal

Primeiro, crie uma conta normal no sistema:

Nome: Jonatan Ott

Email: marlonott75@gmail.com

Senha: (escolha uma senha forte)

🔧 Passo 2: Executar SQL no Supabase

Depois de criar a conta, vá no SQL Editor do Supabase e execute:

-- Promover para admin UPDATE public.users SET role = 'admin', is_premium = true WHERE email = 'marlonott75@gmail.com'; -- Verificar SELECT id, name, email, role, is_premium FROM public.users WHERE email = 'marlonott75@gmail.com';

✅ Passo 3: Fazer Login como Admin

Após executar o SQL, faça logout e login novamente. Você terá acesso ao painel administrativo!

✨ Alternativa Rápida:
Se você já criou a conta, pode executar este comando SQL diretamente:
SELECT public.create_admin( 'marlonott75@gmail.com', 'sua-senha', 'Jonatan Ott' );
